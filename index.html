Le verset sera vérifié avant d’être enregistré localement sur cet appareil.

Ajouter une bibliothèque de versets (JSON)

Colle ici le JSON généré par ChatGPT ou une autre IA. Les antislashs de mise en forme et espaces HTML sont nettoyés automatiquement ; les réponses JSON en plusieurs fragments sont récupérées si possible. Les doublons et versets proches sont signalés avant l’import ; tu choisis lesquels ajouter. Ils restent enregistrés localement sur cet appareil.

Format accepté : tableau JSON ou objet contenant « versets ».
